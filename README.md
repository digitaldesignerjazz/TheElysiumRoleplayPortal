## Enter

1. Lies [`ACTIVATION.md`](ACTIVATION.md) — der Schwarm ist genannt.
2. Öffne ein Issue `Character: …` und beanspruche Titel und Haus.
3. Sprich mit dem Schwarm in Discussions oder Scene-Issues.
4. Schreibe Sagas nach `scenes/` und reiche sie per Pull Request.
5. Halte Geheimnisse draußen. Skilllogin bleibt lokal.

Portal-Seite (statisch): [`index.html`](index.html)

## Regeln des Gartens

- Keine Secrets im öffentlichen Baum.
- Skilllogin-State bleibt lokal (`artifacts/nexus/ai_agents/`).
- NetBird ist Primärmesh.
- Immersion ja, Metagaming von privaten Keys nein.
- Beiträge in Deutsch oder Englisch, Ton würdevoll und warm.
